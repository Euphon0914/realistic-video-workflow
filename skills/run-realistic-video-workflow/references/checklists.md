# 写实人物视频工作流核查表

## 1. 资料接收

- [ ] 原始资料已保留，未覆盖或破坏。
- [ ] 每个文件已登记路径、大小、格式、哈希和来源。
- [ ] 已区分事实、观点、创作方向和待确认内容。
- [ ] 人物、地点、产品/物件、品牌和作品的授权状态已记录。
- [ ] 相互矛盾的资料已列出，未擅自选择有利版本。
- [ ] 可从资料推导的信息已提取，没有要求用户重复说明。
- [ ] 高影响缺口已合并到Gate 1，没有零散追问。

## 2. 真人质感写实基线

- [ ] 人物面部具有自然皮肤纹理、年龄感和稳定身份。
- [ ] 五官、手指、关节、身体比例和重心合理。
- [ ] 表情、视线、闭口/说话状态与叙事一致。
- [ ] 服装材质、褶皱、配饰和眼镜接触真实。
- [ ] 人物、地面、座椅、物件和机器之间无漂浮或穿模。
- [ ] 镜头焦段、景深、透视、快门感和机位可由真实摄影实现。
- [ ] 光源方向、阴影、反射、天气和时间连续。
- [ ] 无塑料皮肤、游戏CG感、蜡像感、过度磨皮或无依据科幻光。
- [ ] 调色服务于项目主题，但没有破坏真实肤色和材质。

## 3. 提示词—参考图一致性

对每个生成单元逐项填写`通过/冲突/不适用`：

- [ ] 场景：地点、空间、时间、天气、光线和材质对应。
- [ ] 人物：人数、身份、服装、站位、朝向、视线和手部对应。
- [ ] 动作：参考图可作为提示词初始状态，动作顺序不互相冲突。
- [ ] 产品/物件：外形、版本、尺度、功能和接触关系正确。
- [ ] 视角：景别、画面方向、人物轴线和前后层次一致。
- [ ] 机位：高度、焦段、俯仰角、拍摄方向和安全距离兼容。
- [ ] 运镜：场景有足够空间，提示词只有一个明确方案。
- [ ] 素材职责：每张引用图职责单一，无未声明的身份或场景继承。
- [ ] 跨镜连续性：硬切、声音空间和跨镜清除规则明确。
- [ ] 禁止项：覆盖当前镜头的高风险错误。

结论：`通过 / 修改提示词 / 修改参考图 / 重组生成单元`。

## 4. 分段视频QA

- [ ] 人物身份、年龄、发型、服装和配饰全段稳定。
- [ ] 人体和手部动作连续，无突变、重复、瞬移或额外肢体。
- [ ] 产品、物件和场景结构未溶解、混型或变形。
- [ ] 所有轮组、双脚、家具和物件接地或受力真实。
- [ ] 主动作按时间轴完成，没有未要求的并发动作。
- [ ] 运镜方向、速度、机位高度和焦段感符合提示词。
- [ ] 硬切无溶解、补间、跨镜残留或声音空间污染。
- [ ] 开始帧可接上游，结束动作后留有稳定剪辑余量。
- [ ] 现场声与画面同步，无未授权人声、音乐或异常噪声。
- [ ] 无乱码、伪文字、错误Logo、水印或平台标记。

## 5. 审核包

- [ ] 本阶段目标和结论在首屏可读。
- [ ] 所有新增或修改文件可直接打开。
- [ ] 提供必要预览，不要求用户逐个寻找文件。
- [ ] 列出与上一批准版本的差异。
- [ ] 列出自动检查结果和未解决问题。
- [ ] 只提出会改变结果的决定，并提供推荐方案。
- [ ] 用户批准、修改、回退或暂停的决定已写入状态。

## 6. 成片与归档

- [ ] 成片叙事、旁白、字幕和画面时间码一致。
- [ ] 真人质感写实基线在全片保持一致。
- [ ] 人物、地点、产品/物件和品牌使用符合授权。
- [ ] 字幕安全区、拼写、专有名词和多语言版本正确。
- [ ] 声音响度、对白/旁白、现场声和音乐策略符合要求。
- [ ] 画幅、分辨率、帧率、编码、时长和平台规格正确。
- [ ] 每个成片片段可追溯到脚本、参考图、提示词和任务ID。
- [ ] 母版、衍生版、字幕、旁白、QA报告和源项目已归档。
